# Gardenia Strings Website v0.2

A static, responsive launch website for Gardenia Strings.

## Included
- Luxury cream-paper visual direction
- Gold, olive, and deep navy palette
- Three approved logo files in `assets/`
- Responsive navigation and subtle reveal animations
- Services, event types, process, and inquiry sections
- Inquiry form that prepares an email to `gardeniastrings@gmail.com`
- `CNAME` file for `gardeniastrings.com`

## Publish with GitHub Pages
1. Create a public repository named `gardeniastrings.github.io`.
2. Upload all files and folders from this package to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. In Porkbun DNS, point `gardeniastrings.com` to GitHub Pages.
7. In the GitHub Pages custom-domain field, enter `gardeniastrings.com`.
8. Enable **Enforce HTTPS** after GitHub confirms the domain.
