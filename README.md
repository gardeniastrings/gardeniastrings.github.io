# Gardenia Strings Website v1.0

## Invitation Paper Edition

This version includes:

- A complete multi-section website
- Layered invitation-card styling
- Torn and deckled paper edges
- Fine botanical line art and gold-foil details
- Responsive mobile navigation
- Ensemble, events, process, and inquiry sections
- A prepared email inquiry form
- Custom-domain CNAME file for gardeniastrings.com

## Publish with GitHub Desktop

1. Unzip this package.
2. Copy everything inside this folder into:
   `Documents/GitHub/gardeniastrings.github.io`
3. Choose **Replace All** when macOS asks.
4. Open GitHub Desktop.
5. Enter a summary such as: `Gardenia Strings v1.0 invitation design`
6. Click **Commit to main**.
7. Click **Push origin**.
8. Wait about one minute and refresh the website.

The `CNAME` file must remain in the repository because the custom domain is `gardeniastrings.com`.
